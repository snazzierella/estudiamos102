# Estudiamos 102

Gamified Spanish 102 Learning Web Application built with React + Vite.

## Structure
- **Unit 1**: *Repaso de Español 101* (Comprehensive review covering all 746 Spanish 101 vocabulary items).
- **Units 2 – 8**: 7 upcoming Spanish 102 units with customizable templates for syllabus and vocabulary.
- **Practice Deck**:
  - `Repaso 101`: Practice all 746 words at once (`All of Unit 1 (Todo el Repaso)`) or select any specific 101 subcategory.
  - Subcategory drill-downs: Nouns, Verbs, Adjectives, Grammar & Conversation, Sentences, and Units 2–8.
- **Quest Campaign**: Progressive levels with Leitner Box spaced repetition and Boss Review Gates for every unit.
- **AI Chat Companion**: Practice conversational Spanish with Elena.
- **Text Adventures**: Contextual scenarios and mini-games.
- **Mistakes Dungeon & Codex**: Re-challenge missed words and reference verb conjugations.

## Scripts
- `npm run dev`: Launch the Vite development server.
- `npm run build`: Build production assets.
- `npm run lint`: Run Oxlint checks.
